# 紫嫈的三年級加油站（期末版）

給國小三年級（三上）用的離線練習網站，範圍為 115 學年度三上**期末（第二次段考）**。期中範圍的題組已全部移除（見下方「已移除」）。

> ⚠️ 期末範圍為**推定**（尚無學校正式通知），待佩如確認：自然、社會依校用卷標示為第 3～4 單元（社會另含第 5 單元探究）；數學 5～9 單元；國語第 7～12 課；英語 Unit 3～4＋Review 2。

## 視覺風格
套用芷媃版風格：米色點點底、白卡片＋深褐 #4a3a32 粗圓角框與實心下陰影、粉彩科目色（粉／薄荷／橘／薰衣草／黃／藍）加珊瑚色強調、膠囊標籤、標題螢光黃底線、珊瑚斜紋進度條、小雞；字體 Zen Maru Gothic（Google Fonts，載入失敗退回 M PLUS Rounded 1c → 系統中文字型）。只改外觀，功能與題庫不變。

## 首頁分類
- 🏁 期末衝刺（跨單元綜合、測驗卷難度）：期末模擬測驗、國／社／自／英綜合、數學期末綜合、多步驟應用題
- 📖 國語（康軒三上）、🔢 數學（康軒三上）、🔤 英語（翰林 Here We Go 1）、🏫 社會（翰林三上）、🔬 自然（翰林三上）、🌱 閱讀理解
- 每科單元頁只有「🏁 期末範圍」一組，依真實單元名稱排列。
- 🔢 數學多了「✏️ 直式除法（逐步練習）」（見下）。

## ✏️ 直式除法（逐步練習，`div.js`）
只做三年級：二位數÷一位數、三位數÷一位數（除數 2～9，商至少兩位）。設定頁可選：題型（可兩個都選）、商的特徵（不限・混合／商沒有0／商中間有0／商個位是0；只選二位數時「商中間有0」停用，因為商最多兩位）、餘數類型（沒有餘數／有餘數／混合練習）、題數（5／10）。設定存在 `p3_div_cfg`。
- 逐步依序填：**試商 → 相乘 → 相減 → 落下**，每一位重複；有餘數時最後再**填餘數**，並**比一比餘數與除數（要＜除數）**。
- 錯一次溫和提示、可按「給我一點提示」（兩段）；同一步錯兩次會幫忙填上答案並說明，再往下算。「換一題」不算題數。
- 題目每次隨機（避開最近 40 題和本回合已出過的）；由 `__p3Div` 測試用掛勾驗證過全部 7560 種題目的步驟推演。
- 結束接現有結果頁與 Google 表單自動回報：科目＝數學、題組＝直式除法；錯題明細寫「算式｜錯在哪一步（例：十位相減 19−16 她答4，正解3）｜正解」。

## 已移除的期中範圍題組
國語 單元一、單元二（cu1、cu2）；數學 第1～4單元（m1～m4）；英語 Starter～Review 1、拼字1、拼字2（e12、e3、e4）；社會 第1、2單元（s1、s2）；自然 第1、2單元（n1、n2）；🏁 期末衝刺的「數學 整冊總複習（單元1～9）」（fm3，含期中範圍，佩如決定刪除）。數學產生器 m1～m4 的程式保留（🏁 期末衝刺的「多步驟應用題」仍會用到其中幾個），只是沒有單元入口。舊錯題本、最近出題紀錄裡指到這些單元的項目，開啟時由 `pruneWB()` 安靜清掉。

## 每回合都不一樣
- 數學：85 個程式產生器（`gen.js`＝單元 1～5 基礎＋`gen2.js`＝單元 5～9 與多步驟應用題），每回合 6 題產生題＋最多 2 題手寫題。
- 其他科：題庫為每回合題數的 3 倍以上；每回合洗牌，並避開最近 3 回合出過的題（`p3_recent`）。閱讀理解 8 篇、每篇 6 題抽 4 題。
- 國語讀音依教育部國語辭典簡編本，沒把握的讀音題不出。

## 檔案
- `index.html`（載入器，檔名帶 `?t=Date.now()`）、`style.css`、`app.js`、`div.js`（直式除法）、`data.js`（題庫）、`gen.js`、`gen2.js`（數學產生器）、`legacy.js`（舊版題庫，只用來轉換舊錯題本）、`validate.js`（`node validate.js`）
- 功能：錯題本、📝 計算紙（✖ 關閉；寫字時不會選取反白文字）、🔊 唸給我聽、英文拼字、📋 複製結果給教練、Google 表單自動回報。
- 自動回報欄位不變：科目＝科別卡名稱（國語／數學…／期末衝刺），題組＝單元名稱。送失敗暫存 `p3_outbox`（最多 50 筆）。
- 舊版 localStorage 錯題本會在開啟時自動轉換成自足格式（`migrateWB()`），不會壞。
