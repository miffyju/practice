# 紫嫈的三年級加油站

給國小三年級（三上）用的離線練習網站：數學（康軒三上 1–5 單元）、國語、閱讀理解、社會（翰林三上 1–5 單元）、自然（翰林三上：植物、磁鐵）、英語（翰林 Here We Go）。

題數：數學 45、國語 30、閱讀 12、社會 42、自然 24、英語 20＋拼字 12+13；另有「📝 期中考衝刺」13 組 197 題（11/5 英語 18＋⭐12＋✏️拼字 15、自然 16＋⭐12、國語 15+15＋挑戰 21+14；11/6 社會 14＋⭐12、數學 20＋⭐13，對應期中考範圍），共 395 題。英語題有「🔊 唸給我聽」按鈕（使用瀏覽器內建 speechSynthesis，不支援的裝置會自動隱藏）。

英文拼字題：看中文意思和 emoji，按 🔊 聽發音，用螢幕上的字母方塊（該字字母打亂＋3 個干擾字母）拼出單字，有 ⌫ 退格和 ✔ 送出，不會叫出系統鍵盤；不分大小寫，答錯會標出拼錯的字母並給首字母提示。
純 HTML/CSS/JavaScript，不需要建置、不連外部資源，可直接放上 GitHub Pages。

- `index.html`、`style.css`、`app.js`：網站本體
- `data.js`：題庫（新增題目照現有格式即可）
- `validate.js`：題庫檢查（`node validate.js`）：每題都有答案/提示/解說、選擇題答案在選項中、數字題用 `check` 算式重算答案、英語 `say` 欄位須為英文、拼字題（type "spell"）答案須為小寫字母且 say 相同、hint 含首字母

本機測試：`python3 -m http.server 8000` 後開 http://localhost:8000/

數學題（數學科、期中考衝刺的數學組與⭐數學挑戰題）有「📝 計算紙」：可用手指或觸控筆在畫面下半部書寫，有黑/藍/紅筆、橡皮擦、復原、清除、關閉；換題自動清空，不存入 localStorage。

作答紀錄與錯題本只存在該裝置瀏覽器的 localStorage。
