# 紫嫈的三年級加油站（期末版）

給國小三年級（三上）用的離線練習網站，範圍為 115 學年度三上**期末（第二次段考）**，並保留整冊總複習。

> ⚠️ 期末範圍為**推定**（尚無學校正式通知），待佩如確認：自然、社會依校用卷標示為第 3～4 單元（社會另含第 5 單元探究）；數學 5～9 單元；國語第 7～12 課；英語 Unit 3～4＋Review 2。

## 視覺風格
套用芷媃版風格：米色點點底、白卡片＋深褐 #4a3a32 粗圓角框與實心下陰影、粉彩科目色（粉／薄荷／橘／薰衣草／黃／藍）加珊瑚色強調、膠囊標籤、標題螢光黃底線、珊瑚斜紋進度條、小雞；字體 Zen Maru Gothic（Google Fonts，載入失敗退回 M PLUS Rounded 1c → 系統中文字型）。只改外觀，功能與題庫不變。

## 首頁分類
- 🏁 期末衝刺（跨單元綜合、測驗卷難度）：期末模擬測驗、國／社／自／英綜合、數學期末綜合、多步驟應用題、整冊數學總複習
- 📖 國語（康軒三上）、🔢 數學（康軒三上）、🔤 英語（翰林 Here We Go 1）、🏫 社會（翰林三上）、🔬 自然（翰林三上）、🌱 閱讀理解
- 每科單元頁分「🏁 期末範圍」與「📚 期中範圍（整冊總複習）」兩組，依真實單元名稱排列。已移除原本的「📝 期中考衝刺」。

## 每回合都不一樣
- 數學：85 個程式產生器（`gen.js`＝單元 1～5 基礎＋`gen2.js`＝單元 5～9 與多步驟應用題），每回合 6 題產生題＋最多 2 題手寫題。
- 其他科：題庫為每回合題數的 3 倍以上；每回合洗牌，並避開最近 3 回合出過的題（`p3_recent`）。閱讀理解 8 篇、每篇 6 題抽 4 題。
- 國語讀音依教育部國語辭典簡編本，沒把握的讀音題不出。

## 檔案
- `index.html`（載入器，檔名帶 `?t=Date.now()`）、`style.css`、`app.js`、`data.js`（題庫）、`gen.js`、`gen2.js`（數學產生器）、`legacy.js`（舊版題庫，只用來轉換舊錯題本）、`validate.js`（`node validate.js`）
- 功能：錯題本、📝 計算紙（✖ 關閉；寫字時不會選取反白文字）、🔊 唸給我聽、英文拼字、📋 複製結果給教練、Google 表單自動回報。
- 自動回報欄位不變：科目＝科別卡名稱（國語／數學…／期末衝刺），題組＝單元名稱。送失敗暫存 `p3_outbox`（最多 50 筆）。
- 舊版 localStorage 錯題本會在開啟時自動轉換成自足格式（`migrateWB()`），不會壞。

本機測試：`python3 -m http.server 8000` 後開 http://localhost:8000/
