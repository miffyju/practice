# 小學三年級練習站

給國小三年級（三上）用的離線練習網站：數學（康軒三上 1–5 單元）、國語、閱讀理解、社會（翰林三上 1–5 單元）、自然（翰林三上：植物、磁鐵）、英語（翰林 Here We Go）。

題數：數學 45、國語 30、閱讀 12、社會 42、自然 24、英語 20；另有「📝 期中考衝刺」12 組 182 題（11/5 英語 18＋⭐12、自然 16＋⭐12、國語 15+15＋挑戰 21+14；11/6 社會 14＋⭐12、數學 20＋⭐13，對應期中考範圍），共 355 題。英語題有「🔊 唸給我聽」按鈕（使用瀏覽器內建 speechSynthesis，不支援的裝置會自動隱藏）。
純 HTML/CSS/JavaScript，不需要建置、不連外部資源，可直接放上 GitHub Pages。

- `index.html`、`style.css`、`app.js`：網站本體
- `data.js`：題庫（新增題目照現有格式即可）
- `validate.js`：題庫檢查（`node validate.js`）：每題都有答案/提示/解說、選擇題答案在選項中、數字題用 `check` 算式重算答案、英語 `say` 欄位須為英文

本機測試：`python3 -m http.server 8000` 後開 http://localhost:8000/

作答紀錄與錯題本只存在該裝置瀏覽器的 localStorage。
