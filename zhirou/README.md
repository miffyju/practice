# 芷媃的五年級加油站

給芷媃（新北文德國小五年級，115 學年度上學期）用的離線練習網站，架構與功能同妹妹紫嫈的三年級練習站。題目已加深（多步驟應用、推理、陷阱、比較判斷、長篇閱讀），目標私中與資優班程度。

題數：「📝 期中考衝刺」5 組基本題 84 題（國語 第1~3課 15、國語 第4~6課 15、數學 第一~五單元 18、自然 第1~2單元 16、社會 第一~二單元 20，含大肚王國 5 題）＋ 5 組「⭐ 挑戰題」33 題（國語 5+5、數學 7、自然 6、社會 10，含大肚王國 4 題），共 117 題。另有「🔤 英文」科目（康軒 Wonder World 5 Unit 1 The Best Drink、Unit 2 Let’s Make Fruit Salad 單字）：基本 18 題、⭐ 挑戰 9 題，有「🔊 唸給我聽」；另有「🔢 數字 0–100 拼寫」（0–100 每個數字一題打字題 101 題＋英翻數字/選拼法 8 題，共 109 題，每回合加權抽 16 題，易錯字 12、13、15、18、20、40、50、80、90、100 權重最高；接受 a hundred；用空格代替連字號算對但會提醒）和「✏️ Unit 1–2 全部單字拼寫」（14 題打字題，水果單複數都算對）；全站共 267 題。數學題（基本與 ⭐ 挑戰）有「📝 計算紙」：畫面下半部的手寫面板（題目留在上半部），Pointer Events 支援手指、觸控筆、滑鼠，黑/藍/紅筆、橡皮擦、復原、清除、關閉；依 devicePixelRatio 繪製、旋轉或縮放時重畫；只存在記憶體，換題自動清空，不寫入 localStorage。打字題（type "text"）不分大小寫、去空白，答錯一次可再試並標出錯的字母，錯題會進錯題本；validate.js 會用獨立的拼字表核對 0–100 每個數字。英文顏色 #b48ee0 同紫嫈網站。首頁另有國語/數學/自然/社會按鈕，裡面是同一批題目。科目顏色同紫嫈網站（國語 #7ec8a9、數學 #ff9f68、自然 #6cc070、社會 #f2b84b），單元按鈕、題目頁標籤與題目卡左邊框都依科目上色（data.js 單元的 color 欄位）。長篇閱讀用題目的 passage 欄位。題目依五上考卷題型與考點改寫，非出版社原題。部署位置：repo miffyju/practice 的 zhirou/（https://miffyju.github.io/practice/zhirou/），資源皆為相對路徑；localStorage 鍵名為 p5zr_*，不會和妹妹的紀錄混在一起。
純 HTML/CSS/JavaScript，不需要建置、不連外部資源，可直接放上 GitHub Pages。

- `index.html`、`style.css`、`app.js`：網站本體
- `data.js`：題庫（新增題目照現有格式即可）
- `validate.js`：題庫檢查（`node validate.js`）：每題都有答案/提示/解說、選擇題答案在選項中、數字題用 `check` 算式重算答案、英語 `say` 欄位須為英文

本機測試：`python3 -m http.server 8000` 後開 http://localhost:8000/

作答紀錄與錯題本存在該裝置瀏覽器的 localStorage。每一回合結束（含錯題本重做）會把成績送到媽媽的 Google 表單：孩子固定為芷媃、送出時間、科目、題組、分數，以及錯題明細（沒有錯題就寫「全對」）。離線時先排進 localStorage 的 p5zr_outbox（最多 50 筆），下次開啟再送。

## 2026-11 更新：每回合題目不同
- `extra.js`：擴充題庫（國語 第1~3、4~6課各 +15，新增「國語 期末範圍（第7~12課）」15 題；自然 1~2 單元 +16，新增「自然 期末：3 水溶液・4 力與運動」18 題；社會 一~二 +14，新增「社會 期末：三・四」21 題）。
- `gen.js`：25 個隨機出題器（數學一~十 22 個、英文單字 3 個），答案由程式計算（分數一律最簡、小數用整數運算）。新單元：🎲 數學 一~五、🎲 數學 六~十（期末）、⭐🎲 數學資優挑戰、🎲 英文單字隨機。
- 固定題庫單元：`p5zr_seen` 記錄每單元最近 3 回合出過的題目，抽題時避開；不夠時用最久沒出現的補。
- 錯題本：隨機題整份題目存進錯題本（舊的 {sid,uid,idx} 紀錄照常可用）；送給媽媽的錯題明細標「單元#隨機」。
- 檢查：`node validate.js`（固定題庫）、`node test-gen.js`（每個出題器出 200 題檢查）。
- 新的 js 檔要加進 index.html 內嵌載入器的 files 清單（目前：data.js、extra.js、gen.js、app.js）。
