# 芷媃的五年級加油站

靜態練習網頁，給芷媃在平板上練習五上期末範圍。目標學校：延平、南山、江翠資優、中山資優。題目難度偏資優／私中，但用五年級能懂的話來講。

**期末範圍（文德國小二次段考，考試約 2027/1/12–13）**
- 國語（康軒）：第七～十二課，另有閱讀階梯二、學習地圖三・四。課名：7 為生命找出口、8 最勇敢的女孩、9 在挫折中成長、10 山中寄情、11 與達駭黑熊走入山林、12 荒島上的國王。
- 數學（康軒）：第六～十單元（異分母分數的加減、線對稱圖形、整數四則運算、面積、柱體錐體和球）。第一～五單元已自選單拿掉（屬期中範圍）；只在錯題本舊資料裡仍可查到。
- 自然（南一）：單元 3 水溶液、單元 4 力與運動（再依活動分成 3-1～3-3、4-1～4-3）。
- 社會（翰林）：第三單元「成為清帝國的領土」、第四單元「土地的利用與開發」（第五單元不考）。再依各課標題分單元。
- 英文（康軒 Wonder World 5）：Drive 資料夾沒有英語卷。依 115 學年教學計畫，上學期為 Unit 3 A Fun Day、Unit 4 My Favorite Subject，以及 Culture & Festivals：Chinese New Year。Unit 1–2 單字放在「期末衝刺」當複習（期末可能仍會用到）。數字 0–100 拼寫保留在英文科目。

首頁分類：各科別（國語、數學、英文、自然、社會）＋「📝 期末衝刺」＋「🏅 奧林匹克數學」。奧數單元依年度（2020–2027 亞太區小學奧林匹亞數學競賽臺灣區初賽歷屆試題，答案取自官方解答頁）以及題型（數論、計數、幾何、應用題、規律）分類，另有「隨機挑戰」用產生器出題，不會出完。每一科再分課／單元。數學與奧數隨機挑戰以產生器出題；其他科用擴充題庫，並以 `p5zr_seen` 避開最近 3 回合出過的題。跨科綜合會同時抽固定題和數學隨機題。需圖才能作答、或文字層無法還原的歷屆題已略過。

作答紀錄與錯題本存在該裝置瀏覽器的 localStorage。每一回合結束（含錯題本重做）會把成績送到媽媽的 Google 表單：孩子固定為芷媃、送出時間、科目、題組、分數，以及錯題明細（沒有錯題就寫「全對」）。離線時先排進 localStorage 的 `p5zr_outbox`（最多 50 筆），下次開啟再送。舊錯題本若仍指向已下架的期中單元，會從 `archive.js` 查出原題，不會壞掉。

## 檔案
- `index.html`：用 `?t=Date.now()` 依序載入 css／js，並有 no-cache meta。
- `data.js`：科目與單元骨架、英文數字 0–100 拼寫。
- `archive.js`：已下架的期中／舊單元題庫，只給錯題本查題。
- `extra.js`：期末各課／各活動的固定題（每單元至少 15 題），並組成衝刺綜合題組。
- `olympiad.js`：奧林匹克數學歷屆填充題（在 extra.js 之後載入）。
- `gen.js`：隨機出題器（數學六～十、英文星期／科目／新年／句型、奧數風格：數字謎、雞兔同籠、植樹、年齡、規律數列、因數個數）。答案由程式計算。
- `app.js`：作答、錯題本、表單、計算紙。填充題（`type: fill`）用只讀答案框加觸控鍵盤（不會叫出系統鍵盤；⌫ 長按或按「清除」可清空；帶分數可按「又」）。說明卡放在答案區正下方，小螢幕會自動捲到看得見的位置。計算紙在書寫時會關掉選取，避免平板觸控筆反白。
- 數學六～十、資優挑戰、期末數學隨機題與奧數產生器：可填數字或分數的題約六成用填充題，其餘維持選擇題；觀念／敘述題仍是選擇題。分數接受等價形式（例如 1又1/2、1 1/2、3/2、1.5）。
- 檢查：`node validate.js`、`node test-gen.js`。

題目依課本範圍改寫，不是出版社原題。閱讀階梯二因掃描檔沒有文字層，改以同主題原創短文練習閱讀策略。
